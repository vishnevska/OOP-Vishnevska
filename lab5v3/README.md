##  Мета роботи
Навчитися реалізовувати поліморфну поведінку за допомогою віртуальних методів та їх
 перевизначення (`virtual` / `override`), а також агрегувати результати 
 поліморфних викликів.
---
##  Реалізація
Ієрархія класів працівників:
**`Employee`** (базовий клас): містить ім'я `Name` та віртуальний метод `CalculatePay()`.
**`HourlyEmployee`**: почасова оплата (`HoursWorked * HourlyRate`).
**`SalariedEmployee`**: фіксований оклад (`WeeklySalary`).
**`CommissionEmployee`**: комісія від продажів (`SalesAmount * CommissionRate`).
У програмі створено колекцію `List<Employee>`, в якій для кожного працівника поліморфно
 викликається метод `CalculatePay()`, після чого обчислюється загальна сума виплат.

##  Відповіді на контрольні запитання
1. **Що таке поліморфізм як він реалізується в C# за допомогою virtual та override?**  
   Поліморфізм — це здатність об'єктів різних класів по-різному реагувати на однакові
    виклики методів. Базовий клас позначає метод як virtual, а похідні класи надають
     свою конкретну реалізацію через override.
2. **Поясніть поняття динамічного зв’язування. Чим воно відрізняється від статичного?**  
   Динамічне зв'язування означає, що конкретна версія методу визначається під час 
   виконання програми (Runtime) на основі реального типу об'єкта, а не під час
    компіляції (Compile-time).
3. **Наведіть приклад, як поліморфізм дозволяє писати більш гнучкий та розширюваний код.**  
   Ми викликом одного циклу `foreach` розраховуємо зарплату для всіх видів працівників.
    Якщо ми додамо новий тип працівника, нам не доведеться змінювати код розрахунку суми.
4. **Які переваги дає використання колекцій базових типів для роботи з поліморфними об’єктами?**  
   Це дозволяє зберігати та обробляти об'єкти різних похідних класів в одному масиві чи
    списку (`List<Employee>`), застосовуючи до них єдиний інтерфейс взаємодії.
