## Мета роботи
Реалізація інтерфейсу `IDisposable` та повного патерну `Dispose` для керування некерованими ресурсами в C#.
---
##  Реалізація
Клас `NetworkStream` імітує мережевий потік:
- **`_disposed`**: Прапорець для перевірки станy об'єкта та запобігання повторному очищенню.
- **`_isStreamOpen`**: Імітація ресурсу (стан потоку).
- **`Send()`**: Надсилає дані або викидає `ObjectDisposedException`, якщо потік закритий.
- **`Dispose(bool disposing)`**: Розділяє звільнення керованих (`disposing == true`) 
та некерованих ресурсів.
- **`Dispose()`**: Публічний метод. Викликає `Dispose(true)` та `GC.SuppressFinalize(this)`.
- **`~NetworkStream()`**:Деструктор для підстраховки(викликає`Dispose(false)`при роботі GC).
---
##  Сценарії (Main)
1. **`using`**: Автоматичний виклик `Dispose()` при виході з блоку.
2. **Явний `Dispose`**: Ручне закриття та перевірка ідемпотентності (повторний 
виклик безпечний).
3. **`GC`**: Демонстрація роботи деструктора через `GC.Collect()` та `GC.
WaitForPendingFinalizers()`.
---
##  Висновок
1. **`using`** — найбезпечніший спосіб роботи з `IDisposable` об'єктами.
2. **Патерн `Dispose`** гарантує правильне та безпечне звільнення ресурсів.
3. **`GC.SuppressFinalize(this)`** економить ресурси, викреслюючи об'єкт із 
черги фіналізації після ручного `Dispose()`.
4. **Деструктор** виступає лише страховою сіткою на випадок забудькуватості розробника.
